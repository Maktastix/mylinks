## Week 1 - History
- One writing system can be used by many languages
- Many fundamental developer tools and terms have historical roots

## Week 2 - Bits and Bytes
- Most computer systems have short-term memory (Volatile, like RAM) and persistent long-term memory (Non-volatile, like SSDs/HDDs)
- Unsigned numbers are non-negative and all bits contribute to the magnitude, while signed numbers can be positive or negative 

## Week 3 - Text Structure
- Markup languages are used to define how text should be displayed or add semantic meaning (Markdown, HTML, XML)
- Common formats for for representing structured data include XML and JSON

## Week 4 - Keyboards and Editors
- Keyboards have 3 attributes to distinguish between them, physical arrangement, visual labeling, and functional/logical software response
- Word processors are convenient for documents intended for reading/printing while text editors are designed for plain text and essential for writing code, and IDEs which have a combination of tools

## Week 5 - CLI (Command Line Interfaces)
- CLIs allow for specifying details to the tiniest level, and can easily create scripts to automate repetitive tasks, especially useful for working remotely
- Doesn't require graphical rendering, less demanding and can therefore be used to control tiny devices
